# nahawandi.com

Static Astro site for Nahawandi, deployed to GitHub Pages by GitHub Actions on every push to `main`.

- **Design:** read [DESIGN.md](DESIGN.md) before changing or adding anything visual, and follow it.
- **Content** lives in `src/data/*.json` and is edited by the owner through `/admin` (Sveltia CMS). Run `git pull` before editing, because the owner may have saved changes there.
- Styles: `src/styles/global.css`. Components: `src/components/`. Pages: `src/pages/`.
- Check phone (375px and 320px) and wide/zoomed-out screens before publishing. Nothing may scroll sideways.
